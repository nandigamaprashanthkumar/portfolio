Put book cover images here (jpg/png).
Then in the Google Sheet "Books" tab, set the CoverURL column to just the file name,
e.g.  atomic-habits.jpg
The site will load it from assets/covers/atomic-habits.jpg (fast, no external fetch).
You can also use a full path (assets/covers/x.jpg) or a normal https:// URL.
Leave CoverURL empty to auto-fetch a cover online.
